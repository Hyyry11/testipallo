# testipallo
Testi joulukuu 25

## Kuvaus (Description)

Testipallo on yksinkertainen Python-moduuli, joka demonstroi testauksen perusteet. 
Testipallo is a simple Python module that demonstrates the basics of testing.

## Ominaisuudet (Features)

- Peruslaskutoimitukset (summa, erotus, tulo)
- Tervehdysfunktio
- Kattavat yksikkötestit

## Testien ajaminen (Running Tests)

Aja testit käyttämällä Pythonin unittest-moduulia:

```bash
python3 test_testipallo.py
```

Tai vaihtoehtoisesti:

```bash
python3 -m unittest test_testipallo.py
```

## Testien tulos (Test Results)

Kaikki testit pitäisi mennä läpi onnistuneesti:
- ✓ Summan laskeminen
- ✓ Erotuksen laskeminen  
- ✓ Tulon laskeminen
- ✓ Tervehdys oletusarvolla
- ✓ Tervehdys mukautetulla nimellä
